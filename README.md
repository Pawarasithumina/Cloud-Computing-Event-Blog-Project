# Cloud Computing Event Blog Project

##  Project Overview

**Cloud Computing Event Blog Project** is a web-based event blog application developed as the **Final Project for the Cloud Computing module**.

The project demonstrates how cloud computing technologies can be used to deploy and host a dynamic web application. The platform allows users to explore and interact with event-related content while demonstrating the practical use of **cloud-based infrastructure, hosting, and storage services**.

The application was developed using **HTML, CSS, and JavaScript** and deployed using **Amazon Web Services (AWS)**.

The main focus of the project was to understand how a web application can be moved from a local development environment to a cloud-based infrastructure, making it accessible through the internet while considering important cloud computing concepts such as **availability, scalability, accessibility, and reliability**.

---

##  Project Objectives

The main objectives of this project were to:

* Design and develop an event-focused blog application.
* Deploy a web application using cloud computing technologies.
* Host the application using AWS cloud infrastructure.
* Explore the use of cloud-based storage and deployment services.
* Understand the process of deploying a web application to the cloud.
* Demonstrate how cloud infrastructure can support web applications.
* Provide an accessible platform for viewing and managing event-related content.
* Apply cloud computing concepts to a practical application.

##  Application Overview

The Event Blog platform is designed to provide users with a centralized place to explore event-related content.

The application focuses on:

*  Event information
*  Event-related blog posts
*  Event content and media
*  User interaction with event information
*  Cloud-based hosting
*  Cloud-based storage

The application is designed to be accessible through a web browser after being deployed to the cloud.

##  Cloud Computing Component

A major component of the project was deploying the web application using **Amazon Web Services (AWS)**.

Instead of running the application only on a local computer, cloud infrastructure was used to make the application accessible through the internet.

The project demonstrates the basic workflow of:

```text

        │
        ▼

        │
        ▼
AWS Cloud Services
        │
        ▼
Cloud Hosting & Storage
        │
        ▼

        │
        ▼
Users Access the Application
```

This provided practical experience in understanding how cloud platforms can be used to host and support web applications.

##  Deployment

The project demonstrates the process of deploying a web application to a cloud environment.

The general deployment workflow was:

### 1. Develop the Application

The event blog was developed using HTML, CSS, and JavaScript.

### 2. Prepare Application Files

The project files were organized and prepared for deployment.

### 3. Configure AWS Services

The required AWS cloud services were configured to support application hosting and storage.

### 4. Deploy the Application

The website files were deployed to the configured AWS environment.

### 5. Test the Application

The deployed application was accessed through a web browser to verify that the application and its components worked correctly in the cloud environment.
