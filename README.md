# Cloud-Computing-Event-Blog-Project

This project demonstrates the deployment of a dynamic event blog website using cloud computing technologies. It focuses on scalability, accessibility, and reliability by leveraging cloud-based hosting and storage solutions. The platform allows users to explore, share, and manage event-related posts efficiently.

🔹 Objectives:

1. Design and host a blog application on a cloud platform

2. Implement storage and deployment using cloud services

3. Showcase the practical application of cloud infrastructure in web development

💻 Tech Stack:

1. HTML, CSS, JavaScript

2. Cloud Platform (AWS)
